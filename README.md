# AI-Driven Public Grievance and Resolution Time Tracking System

## Project Overview

The AI-Driven Public Grievance and Resolution Time Tracking System is an intelligent platform designed to automate and improve the public grievance handling process. The system enables users to submit complaints digitally, track their status in real time, and receive updates throughout the complaint lifecycle.

The project integrates Artificial Intelligence and Machine Learning techniques to automatically analyze grievance content, categorize complaints, and predict resolution timelines based on historical patterns. This reduces manual effort, improves efficiency, and helps authorities prioritize and resolve issues more effectively.

The application follows a multi-tier architecture consisting of a React frontend, a Spring Boot backend REST API, and an AI Microservice developed using Python for NLP-based classification and prediction tasks. The system also includes authentication, complaint tracking, dashboards, and administrative management features.

## Key Features

- User Registration and Login with JWT Authentication
- Complaint Submission and Tracking
- AI-based Complaint Categorization
- Resolution Time Prediction
- Status Updates and Resolution Tracking
- User Dashboard
- Admin Dashboard
- REST API Integration
- Real-time Complaint Lifecycle Management
